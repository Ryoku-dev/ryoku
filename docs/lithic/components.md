# Components

Lithic components share four recipes. Units are dp unless noted. Type styles
come from [design.md](design.md#4-type), roles from
[palette.md](palette.md), and window composition from
[layout.md](layout.md). Ryoport file names are the reference.

| Recipe | Rule |
|---|---|
| Hover | Filled controls mix the fill toward white by 0.10; a tonal plaque mixes `field` toward `fg` by 0.06. Transparent controls show ink at alpha 0.10. Planes step one tone up. Fade in over 160 ms and out over 100 ms. |
| Press | Plaques deepen the cut by 4 and sink content by 1 over 90 ms. Rows and menu items dip by adding `fg` at alpha 0.08. |
| Focus | Draw a 2 dp `fg2` ring 2 dp outside the control, with the cut grown by 2. Fade in over 120 ms and out over 100 ms. Show it only for keyboard focus. |
| Disabled | Draw the whole control at alpha 0.5 and suppress hover. |

Two shape rules hold for every component:

- **Fill shows the cut.** A control with a cut has a fill or a hairline that
  clears APCA Lc 15 against its plane. A quiet plaque draws no cut at rest
  and shows it with its hover fill.
- **Nested cuts are concentric.** A cut inside another cut at an inset takes
  `inner = outer - inset * (2 - sqrt(2))`, rounded. Cut sizes themselves do
  not change.

## Foundation

### Icon

Use Material Symbols Sharp everywhere. QML and the web set its ligatures in
the font that `tokens.json` `font.icons` names. Gio draws the same symbols
from package `symbols`: IconVG data at weight 400 in the outline style, with
`_fill` variants where a list entry asks for them, generated by
`cmd/lithic-symbols` from a list file. Icons inherit the component ink, never
carry state by themselves, and every icon-only action has an accessible
description. Reference: `ui/icons/icons.go` and `ui/kit/osicon.go`.

Library: QML Lithic.Glyph, web .l-glyph, Go kit.Icon, terminal -

### CutRect

Fill or stroke a rectangle with independent 45 degree cuts on its four
corners. A 1 dp stroke is drawn inside. Its inner cut is
`cut - width * (2 - sqrt(2))`, which keeps the stroke even around the
chamfer. Reference: `ui/kit/draw.go`.

Library: QML Lithic.CutRect, web .l-cut, Go kit.FillCut and kit.StrokeCut, terminal -

### Notch

Draw the top-left triangle `(x, y) (x+12, y) (x, y+12)`. A tablet uses it for
state. Settings uses one amber notch for an available update. An icon plaque
may use one for a pending change. Reference: `ui/kit/draw.go`.

Library: QML Lithic.Notch, web .l-notch, Go kit.Notch, terminal term.RenderNotch

### Blade

Draw a bar with a 45 degree leading edge. The trailing top corner is cut by
the bar height. Blades mark progress, meters and the current tab.
Reference: `ui/kit/draw.go`.

Library: QML Lithic.Blade, web .l-blade, Go kit.Blade, terminal term.RenderBlade

### Flake

A flake is a parallelogram 1.4 by 0.7 of its nominal size, with 45 degree
short sides. Idle has a 1.5 dp `vein` outline. Active fills with
`stone(tone)`. Becoming starts on `vein` and fills with `lapis` to the
progress fraction. A nominal size of 9 produces a flake about 13 wide and 6
high. Reference: `ui/kit/token.go`.

Library: QML Lithic.Flake, web .l-flake, Go kit.Flake, terminal term.RenderFlake

### Hatch

Draw 1 dp `fg` lines at 45 degrees, 6 dp apart and alpha 0.30. It is an
engraved chart field, not a general background texture. Reference:
`ui/kit/chart.go`.

Library: QML Lithic.Hatch, web .l-hatch, Go kit.Hatch, terminal -

### FocusRing

The keyboard focus ring is a 2 dp `fg2` stroke 2 dp outside the target. Grow
the target cut by 2 and fade the ring in over 120 ms, out over 100 ms.
Pointer focus does not show it. Reference: `ui/kit/focus.go`.

Library: QML Lithic.FocusRing, web .l-focus-ring, Go kit.FocusRing, terminal -

## Controls

### Plaque

A plaque is a cut button. Normal height is 40 with 18 horizontal inset, cut
7, icon 19 and an 8 gap. Small height is 32 with 13 inset, cut 6, icon 17 and
a 6 gap. Both use `label` type. Its tiers run from loudest to quietest: gold,
line, tonal, quiet; danger stands apart.

| Kind | Fill | Ink | 1 dp hairline | Use |
|---|---|---|---|---|
| gold | `gold` | `onGold` | none | the one consequential action in the view |
| line | none | `goldInk` | `goldInk` | actions beside the gold one |
| tonal | `field` | `fg` | none | secondary verbs: open, edit, turn off, replace |
| quiet | none | `fg2` | none | view controls, cancel and the least of several verbs |
| on | `sel` | `onSel` | none | a selected choice |
| danger | `jasper` | `inkOn(jasper)` | none | the direct destructive action |
| danger line | none | `jasper` | `jasper` | an outlined destructive action |

A tonal plaque hovers to `mix(field, fg, 0.06)` and presses like any plaque.
A quiet plaque shows only its ink at rest; under the pointer its ink fills the
cut at alpha 0.10. A view spends gold on one plaque; the rail's New belongs to
the frame. A busy plaque swallows presses and may show Working. Navigation
never uses gold. Reference: `ui/kit/button.go`.

Library: QML Lithic.Plaque, web .l-plaque, Go kit.Plaque, terminal term.RenderPlaque

### SplitPlaque

The main plaque and a 40 wide more segment sit 2 dp apart and share one
outline. The main segment cuts only its leading corners. The more segment
cuts only its trailing corners. Each has independent hover, press and focus.
It takes every plaque kind. The `expand_more` arrow becomes `expand_less`
while its menu is open. Reference: `ui/kit/splitbutton.go`.

Library: QML Lithic.SplitPlaque, web .l-split-plaque, Go kit.SplitPlaque, terminal term.RenderSplitPlaque

### IconPlaque

An icon plaque is square with no label: 40 with a 20 icon, or 32 with an 18
icon when small, cut 6. It accepts every plaque kind and may carry one mineral
notch. Reference: `ui/kit/iconbutton.go`.

Library: QML Lithic.IconPlaque, web .l-icon-plaque, Go kit.IconPlaque, terminal -

### TextField

The field is 44 high, cut 7, with 14 horizontal inset and `body` text. It
fills with `field` and carries a 1 dp `edge` hairline inside the cut at rest,
wherever it stands, so it reads on a pane, a slab or in a dialog alike.
Placeholder text is `fg3`. An optional label above uses `detail` in `fg2`,
and a help line below uses `caption` in `fg3`, each 4 away. Keyboard focus
turns the hairline `fg2`. An error turns the hairline and the help text
`jasper`. Secret fields mask with `•` and place a 32 quiet reveal plaque 6
from the trailing edge. The same fill and hairline hold for Search, the
Picker anchor and the Stepper's value. Reference: `ui/kit/textfield.go`.

Library: QML Lithic.TextField, web .l-text-field, Go kit.TextField, terminal term.RenderTextField

### Search

Search reserves 42 on the leading side for a 20 `search` icon at 14. Its
default width is 280. A trailing shortcut hint uses `fg3`. Escape clears the
text. When text exists, a 32 quiet clear plaque appears and returns focus
after clearing. Reference: `ui/kit/search.go`.

Library: QML Lithic.Search, web .l-search, Go kit.Search, terminal term.RenderSearch

### Toggle

The track is 40 by 22, cut 4, with a 14 knob cut 2 at a 4 inset. Off uses a
`stone4` track with a 1 dp `vein` hairline and `fg2` knob. On uses `sel` and
`onSel`. Hover adds `fg` at alpha 0.06. The knob glides for 240 ms and the
tone changes over 320 ms. The label is 8 away in `label` type. Space toggles
it. Reference: `ui/kit/toggle.go`.

Library: QML Lithic.Toggle, web .l-toggle, Go kit.Toggle, terminal term.RenderToggle

### Slider

The slider is 32 high and 160 wide by default. Its `field` track is 6 high,
the completed part is an `fg2` blade, and the `sel` handle is 8 by 20 with
cut `min(width/2, height/4)`. Arrow keys step it and Home and End jump to its
ends; a key that moves it reports the change as a drag does, and a key at a
bound reports nothing. Reference: `ui/kit/slider.go`.

Library: QML Lithic.Slider, web .l-slider, Go kit.Slider, terminal -

### Stepper

Two small quiet icon plaques, `remove` and `add`, sit 8 either side of the
value. The value stands in a 32 high field cut 6, with the `field` fill and
`edge` hairline of a TextField. The unit follows 4 later in `fg3`. Disable an
end plaque at its bound. Reference: `ui/kit/stepper.go`.

Library: QML Lithic.Stepper, web .l-stepper, Go kit.Stepper, terminal term.RenderStepper

### Filters

Filter chips are 32 high, 13 inset, cut 6 and 4 apart in `label` type. A
resting chip has no fill: `fg2` ink on the plane, and hover shows the `field`
fill inside its cut.
A selected chip is a `sel` fill with `onSel` ink; the fill glides between
chips over 240 ms. A count follows the label by 6 in `caption` with tabular
figures. Use filters to narrow a list, with live counts. Reference:
`ui/kit/filters.go`.

Library: QML Lithic.Filters, web .l-filters, Go kit.Filters, terminal term.RenderFilters

### Segmented

A segmented control picks one of two to five options that are worth seeing
at once: follow, dark or light; Rashin or Teams; the kind of a schedule. More
options, or labels too long to share a row, take a Picker. Views of one
resource take Tabs, and narrowing a list takes Filters.

- **Track:** `field` fill with a 1 dp `vein` hairline, cut 7, 36 high
  (`size.segmentHeight`). One size only.
- **Segments:** equal width, labels in `label` type. Its natural width is the
  widest label plus 21 on each side, times the count, plus the insets; a
  caller may stretch it.
- **Selected segment:** inset 4 (`size.segmentInset`), cut 5 (`cut.segment`,
  concentric with the track), a `sel` fill and an `onSel` label.
- **Other segments:** `fg2` label; hover shows the ink at alpha 0.10.
- **Motion:** the selection glides to its new segment over 240 ms on the one
  curve. Previews draw final values on the first frame.
- **Keys:** the arrow keys move the selection, Home and End jump to the ends.
  Disabled draws the whole control at alpha 0.5.

Lithic's own; Ryoport has no reference.

Library: QML Lithic.Segmented, web .l-segmented, Go kit.Segmented, terminal -

### Tabs

Tabs use a 44 high strip above a 1 dp `vein` baseline. Each label is its text
width plus 24. The current label is `fg`; other labels are `fg3`, fading to
`fg2` on hover. A 3 dp `fg` blade moves and resizes over 240 ms. Left and
Right move focus and selection. Keep at most five tabs per resource kind.
Reference: `ui/kit/tabs.go`.

Library: QML Lithic.Tabs, web .l-tabs, Go kit.Tabs, terminal term.RenderTabs

### Disclosure

Disclosure grows optional content to its measured height and fades it in over
200 ms. Closing content is inert. Open it with a quiet plaque or a toggle,
never a bare chevron. Reference: `ui/kit/disclosure.go`.

Library: QML Lithic.Disclosure, web .l-disclosure, Go kit.Disclosure, terminal term.RenderDisclosure

### ChordField

ChordField holds one keyboard shortcut on the text field's surface: 44 high,
cut 7, at least 160 wide. At rest the chord shows as keycaps from a 14 inset,
4 apart with no "+" between them. Each keycap is a 24 high cut 3 plate with a
`field` fill and a 1 dp `edge` hairline, its face in `label` type 8 from each
side. An empty field shows its placeholder, "Not set", in `fg3`.

Click, Enter or Space starts recording: the surface takes the field's focus
hairline and reads "Press a shortcut" in `fg2`. A key with at least one of
Super, Ctrl, Alt or Shift held, or a function or media key alone, records the
chord. Escape or losing focus cancels, and Backspace or Delete clears.
Shifted symbols fold back to their key, so Shift+1 records as `Shift+1`. The
field never changes its own chord; the host decides, and holds the
compositor's shortcut inhibitor while the field is recording. A clash shows a
`caption` line in `jasper` 4 below the surface: "Already used by Close
window".

Chord text is canonical: Super, Ctrl, Alt and Shift in that order, then the
key, joined by "+", as in `Super+Shift+Return`. Key names follow Ryoku's
`wm.NormChord` and keycap faces follow `wm.DisplayKeys` ("Page Up", "Num 3").
Gio cannot see letters on non-Latin layouts, Print, Insert, F13 to F24 or
media keys; the Go README lists the gaps.

Library: QML Lithic.ChordField, web .l-chord-field, Go kit.ChordField, terminal -

### ColorField

ColorField holds one colour. A 44 square plate shows it over a Hatch, so
transparency reads, with a 1 dp `edge` hairline and a 3 cut. The hex value
sits 8 to the right in a mono text field whose trailing quiet icon plaque
opens a Popover cut like a Menu: the host's role swatches, each a 20 plate
beside its name with the current one checked, a Hex field, and an Opacity
slider when transparency is allowed. Choosing a swatch or committing valid hex
with Enter or by leaving the field picks the colour. `#abc`, `#aabbcc` and
`#aabbccdd` are accepted and written back as lowercase `#rrggbb` or
`#rrggbbaa`. Anything else shows the field's error state, "Use a colour like
#ce5e32", and picks nothing.

Library: QML Lithic.ColorField, web .l-color-field, Go kit.ColorField, terminal -

## Lists, containers and state

### Tablet

A resource row is a `stone2` tablet, 56 high or 48 at compact density,
square apart from its 12 notch. Content starts at 16: a 32 mark, 13 gap,
title in `row` over one facts line, then a trailing area at least 72 wide
with claim over proof and 12 trailing inset.

Hover or list focus fades to `stone3` and replaces claim and proof with the
row's one action. A selected row is a `sel` fill; its ink is `onSel` and its
quiet ink `onSel2`. Becoming adds a 2 dp `lapis` blade along the bottom.
Click selects and double click runs the primary action. Reference:
`ui/kit/row.go`.

Library: QML Lithic.Tablet, web .l-tablet, Go kit.Tablet, terminal term.RenderTablet

### RowList

Rows sit 4 apart. One selection, a `sel` fill, is drawn behind the selected
row, glides to its new row over 240 ms and follows it while scrolling. The
scroll thumb is a 3 wide `vein` blade with a 12 minimum. A wheel notch glides
120 dp over 140 ms. Trackpad deltas follow the fingers at the screen scale.
Reference: `ui/kit/rowlist.go` and `scroll.go`.

Library: QML Lithic.RowList, web .l-row-list, Go kit.RowList, terminal term.RenderRowList

### ScrollRail

ScrollRail is the scroll thumb for any scrolling pane that is not a RowList.
It shows only while the content overflows: a 3 wide blade with both ends cut
at 45 degrees and a 12 minimum, in `edge` at rest and `fg3` while hovered or
dragged, standing alone where RowList's `vein` thumb has its selection beside
it. Dragging the thumb scrolls; a press on the track pages by one view over
140 ms. Its pointer target reaches 8 into the pane, and the wheel stays with
the pane. On the web it is the `.l-scroll` utility; Firefox draws its own thin
square thumb in the same roles.

Library: QML Lithic.ScrollRail, web .l-scroll, Go kit.ScrollRail, terminal -

### GroupHeader

The title uses `group` and the count `caption` with tabular figures, both
`fg3`. Insets are 14 top, 6 bottom, 6 left and 4 right. Fleet groups appear
only when populated and run Needs you, Pinned, Running, Becoming, Stopped.
Reference: `ui/kit/groupheader.go`.

Library: QML Lithic.GroupHeader, web .l-group-header, Go kit.GroupHeader, terminal term.RenderGroupHeader

### Skeleton

Skeletons are static `stone2` tablets 4 apart with two `stone3` bars, each 8
high and 8 apart, at 60 and 35 percent of the width. Reference:
`ui/kit/skeleton.go`.

Library: QML Lithic.Skeleton, web .l-skeleton, Go kit.Skeleton, terminal -

### Empty

Centre a 72 octagonal `vein` frame with a 30 `fg3` icon, then a `title`, a
`body` no wider than 420, and plaques 8 apart. The copy names the next step.
Reference: `ui/kit/empty.go`.

Library: QML Lithic.Empty, web .l-empty, Go kit.Empty, terminal term.RenderEmpty

### Pane

A pane is one flat plane with its two top corners cut 16 and bottom corners
square. Rail and list panes use `stone1`; the work pane uses `stone2`. Panes
start 10 below the window edge and sit 8 apart. Reference:
`ui/app/layout.go`.

Library: QML Lithic.Pane, web .l-pane, Go kit.Pane, terminal -

### MineralField

The selected resource header sits on `mineralField(tone)`: `stone2` mixed
0.17 toward jade, 0.15 toward lapis, amber or jasper, and `stone3` for idle.
State changes fade over 320 ms. Palette changes snap. Reference:
`ui/kit/field.go`.

Library: QML Lithic.MineralField, web .l-mineral-field, Go kit.MineralField, terminal term.RenderMineralField

### Header

Header insets are 30 top, 36 sides and 26 bottom. A 44 mark and the name sit
13 apart. The name uses `name`, or `sentence` below 640 width. Proof follows
8 below, note 4 below, marks 4 below, acts 21 below, and optional content 21
below that. Acts are one gold split plaque, line or tonal plaques and a quiet
overflow plaque. Reference: `ui/pages/common/header.go`.

Library: QML Lithic.Header, web .l-header, Go kit.Header, terminal -

### Slab

A slab is a container inside a pane: a `slab` fill with a 1 dp `vein`
hairline inside a 7 cut, and a 21 inset. It groups settings, forms and quiet
board sections. A slab lifts and never sinks: in dark mode it is lighter
than the plane it stands on, and in light mode it shares the work pane's
tone and its hairline sets it off. Rows inside are separated by `vein` lines
that keep the 21 inset. Reference: `ui/kit/draw.go`.

Library: QML Lithic.Slab, web .l-slab, Go kit.Slab, terminal term.RenderSlab

### Section

A section places a `section` title 13 above its body and leaves 21 below the
slab. Major full-page regions use 55 between them. Reference:
`ui/pages/settings/view.go`.

Library: QML Lithic.Section, web .l-section, Go kit.Section, terminal term.RenderSection

### SettingRow

SettingRow is one setting in a settings slab. Its title is `row` type in
`fg`, with an optional `detail` line in `fg2` 2 below it; both wrap and never
elide, since translations run long. The control sits at the right,
vertically centred, at most 320 wide, with 21 between it and the text. A row
is at least 44 high, and rows stack 13 apart with a 1 dp `vein` line centred
in the gap; the first row draws no line.

A changed row adds "Changed" in `detail` type and `fg3` on the title's
baseline, 13 after it, and a small quiet reset icon plaque 8 before the
control. The plaque's slot stays reserved while the row is changed, so the
control never shifts; the plaque shows while the row is hovered or holds
focus. An unavailable row disables its control and shows the reason in `fg3`
in place of the detail.

A row the whole of which acts, such as a toggle or a hand-off, takes the
pointer and Enter or Space; only such rows show hover and press, on a plane
that bleeds 8 to each side and 4 above and below with a 6 cut. When search
lands on a row, that plane appears at the hover tone and fades to clear over
1600 ms on the chisel curve, once; with reduced motion it holds until the
host clears it.

Library: QML Lithic.SettingRow, web .l-setting-row, Go kit.SettingRow, terminal -

### DesignTile

DesignTile is one look in a gallery: a bar style, a lock screen, a launcher.
It is a 6 cut `slab` tile with a 1 dp `vein` hairline. A preview fills the top
at 16:10 inside a 4 inset, cropped to fill and clipped to the concentric cut,
or a Hatch on `field` while there is none. Below it, 8 in and 13 from the
sides, the title in `row` type shares a line with the resource mark: Light,
Standard or Heavy in `detail` type, Heavy in `amber`. The second line always
reserves 32, holding the status in `caption` and `fg2`, or the reason the
look cannot be used, and an optional small action plaque at the right, so
tiles in a row align.

The look in use takes a `sel` plane under its text block; a selected tile is
`sel` whole. On `sel`, ink turns `onSel`, and an action that is not gold
takes the `on` kind, since gold ink on bone reads poorly. An unavailable
tile dims its preview, and a busy one shows Working before its status.

Library: QML Lithic.DesignTile, web .l-design-tile, Go kit.DesignTile, terminal -

### DesignGallery

DesignGallery lays design tiles in a grid: as many columns as fit tiles of
at least 200, 8 apart so a focus ring never touches a neighbour, each tile
stretching up to 260. The arrow keys move the selection by tile and by row,
Home and End jump to the ends, and Enter activates the selected look.

Library: QML Lithic.DesignGallery, web .l-design-gallery, Go kit.DesignGallery, terminal -

### Facts

Facts are 44 high label and value rows separated by 1 dp `vein` lines. Labels
use `fg3` in a 140 column. Values use `fg`, switching to mono only for literal
data. An absent value is `-`. Reference: `ui/kit/facts.go`.

Library: QML Lithic.Facts, web .l-facts, Go kit.Facts, terminal term.RenderFacts

### Aside

The draft aside is a standard slab: `slab` fill, 1 dp `vein` hairline, cut 7
and 21 inset. Its `title` names what saving will make or write. A note under
it uses `detail` in `fg2`. Facts and literal previews update as the form
changes; preview text uses `monoSm` on an inner `field` block cut 6 with 13
inset. Reference: `ui/pages/common/draft.go`.

Library: QML Lithic.Aside, web .l-aside, Go kit.Aside, terminal term.RenderAside

### DraftColumns

Keep a draft form at no more than 600 wide. Below 820 available width, its
aside follows the form and is no wider than 600. From 820, the aside sits 34
to the right, takes 36 percent of the available width and clamps from 300 to
400. A missing aside leaves the form alone at reading width. Reference:
`ui/pages/common/draft.go`.

Library: QML Lithic.DraftColumns, web .l-draft-columns, Go kit.DraftColumns, terminal term.RenderDraftColumns

### Claim

A claim is a Flake beside a plain state word in `label`. The word uses the
tone's mineral, or `fg2` for idle. Pair it with the proof that supports the
claim. Reference: `ui/kit/token.go`.

Library: QML Lithic.Claim, web .l-claim, Go kit.Claim, terminal term.RenderClaim

### Marks

Marks are resource traits in `detail` type, set apart by a 13 dp space with
no separator glyph. Disposable is amber and always first, followed by Instant

`ui/pages/common/marks.go`.

Library: QML Lithic.Marks, web .l-marks, Go kit.Marks, terminal term.RenderMarks

### Sentence

Sentence composes spans without turning the whole line into data type. A span

Reference: `ui/pages/common/sentence.go`.

Library: QML Lithic.Sentence, web .l-sentence, Go kit.Sentence, terminal term.RenderSentence

## Overlays and navigation

### Popover

Popover anchors content 8 from its control, below when space permits, above
otherwise, and clamps it to the window. Its own full-window catcher swallows
an outside press before closing it. It enters over 160 ms while sliding the
last 6, and exits over 100 ms while sliding 4 back. Closing content is inert
and blocks underlying pointer input. Only one popover is open. Reference:
`ui/kit/popover.go`.

Library: QML Lithic.Popover, web .l-popover, Go kit.Popover, terminal -

### Menu

A menu is `stone4`, cut 8, 220 to 360 wide, with 6 vertical padding. Items
are 40 high with 16 inset, a 20 icon, 12 gap, `label` text, and shortcut 13
after in `fg3`. A checked item shows a `check` glyph in `fg2` at the trailing
edge, in the shortcut's place; a menu never marks it with a `sel` fill.
Hover mixes `fg` into `stone4` at alpha 0.06 because nothing is above the top
plane; it never steps down to `stone3`. Press mixes `fg` into `stone4` at
alpha 0.08. Danger ink is `jasper`; disabled ink `fg3`. Dividers are 1 dp
`vein` with 8 inset. Reference: `ui/kit/menu.go`.

Library: QML Lithic.Menu, web .l-menu, Go kit.Menu, terminal term.RenderMenu

### Picker

The 44 high anchor is a field: `field` fill and 1 dp `edge` hairline, cut 7,
at least 160 wide and inset 14. Its label uses `detail` in `fg2`, its value
uses `body`, and its 20 `expand_more` arrow uses `fg2`. Hover adds `fg` at
alpha 0.06. It opens Menu inside Popover, with the current option checked.
Reference: `ui/kit/picker.go`.

Library: QML Lithic.Picker, web .l-picker, Go kit.Picker, terminal term.RenderPicker

### Dialog

Use Dialog for a protected decision or a focused catalogue choice, not a
draft. The `stone4` slab is cut 16 with a 1 dp `vein` hairline, at least 16
from the window, with 34 padding. Width defaults to 520 and is configurable;
the catalogue system dialog uses 720. An optional title uses `sentence` with
a 21 gap. Actions follow after 34, flow from the start edge and sit 8 apart.

The full-window scrim catches and swallows outside presses. The dialog enters
over 300 ms while rising 12 and exits over 160 ms while dropping 8. It blocks
pointer input beneath until the exit ends. Reference: `ui/kit/dialog.go`.

Library: QML Lithic.Dialog, web .l-dialog, Go kit.Dialog, terminal term.RenderDialog

### Confirm

Confirm composes Dialog with body, Cancel and a danger or gold action. The
quiet action reads Cancel unless the host names it, such as Revert when a
change is kept or undone. It may require the resource name in a TextField 21
below the body before enabling the action. The action names the verb, never
Yes. Reference: `ui/kit/confirm.go`.

Library: QML Lithic.Confirm, web .l-confirm, Go kit.Confirm, terminal term.RenderConfirm

### Tooltip

After 600 ms of pointer hover, show a `stone4` slab cut 4 with a 1 dp `vein`
hairline, 6 by 8 padding and `caption` text, no wider than 320. It sits 8 from
the anchor and enters over 300 ms with an 8 slide. Reference:

### Placard

A placard is a `sel` slab 48 high, cut 8, with a 1 dp `vein` hairline. It is
no wider than 560 and sits 24 above the bottom edge. Up to three stack 8
apart. Text uses `onSel` with 16 inset. An optional action such as Undo is a
32 high `onSel` plaque. A 2 dp `onSel` blade drains across its 5 s life. It
enters over 300 ms rising 8.
Reference: `ui/kit/placard.go`.

Library: QML Lithic.Placard, web .l-placard, Go kit.Placard, terminal term.RenderPlacard

### Rail

Rail owns Home, Fleet, New and Activity, with Settings at the bottom.
Destination icons are 21. Expanded tiles are 64 in an 88 rail; medium tiles
are 56 in a 72 rail. The current tile is a `sel` fill that glides over
240 ms; with no current destination, as on a host's own home view, no tile is
filled, and the next one fills in place without gliding. Expanded tiles all
take the width of the widest label plus 4 on each side, from 64 up to 80. A
label wider than that wraps to two centred lines, breaking inside a word only
when one word alone is too long, and its tile grows by one caption line. A
host with other destinations keeps the same shape: it can hide New and its
slot, stand every destination from a foot index on at the bottom in reading
order, and mark one destination with an amber Notch at its top left, such as
a pending update. Compact gives the home mark, New and each destination an
equal column in a 64 high bottom bar with 48 high tiles, so it suits five or
fewer; a host with more turns the bar off and navigates from its list pane.
Reference: `ui/app/rail.go`.

Library: QML Lithic.Rail, web .l-rail, Go kit.Rail, terminal -

### BrandMark

### AppFrame

AppFrame fills the window with `ground`, selects expanded, medium or compact
at 1280 and 760, and composes Rail, optional list Pane, work Pane, overlays
and window controls. It owns the compact bottom bar, which a host with many
destinations turns off so the panes run to the bottom, passes the Rail's
options through, and keeps overlay order and Escape behavior consistent.
Reference: `ui/app/layout.go`, `rail.go`, `overlays.go` and `window.go`.
