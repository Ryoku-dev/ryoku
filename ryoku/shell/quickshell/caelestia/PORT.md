Library layout (2026-10-21): the port is an importable QML library, like inir. `bin/ryoku-dev-caelestia-library` rewrites every `import qs.x` to `import caelestia.x` and writes a qmldir in each folder (singletons from `pragma Singleton`); run it again after a sync from upstream (`--check` reports drift). The ryoku-shell daemon puts the quickshell config root on the import path, so the Ryoku shell can load the original panels. `root:` paths in `utils/Paths.qml` resolve against this folder, not the running shell's.
