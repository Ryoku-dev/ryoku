# Kairos

Kairos is Ryoku's clock-island subshell in Android 17's Material 3 Expressive style. The island shows volume, brightness and new notifications as you get them, opens into a quick-settings shade with paged tiles, media, notifications and a power menu, and carries its settings window and a matching app drawer loaded only while selected.

Ryoku ships Kairos under GPL-3.0-or-later. Select it from Ryoku Settings > Desktop > Bar or with `ryoku-shell barstyle kairos`.
